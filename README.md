Polymarket RUB Converter
Расширение для Chrome, которое показывает сумму ставок на Polymarket в рублях. Рядом с каждой ставкой вида 5,641 @ 1.82 добавляется бейдж с суммой в ₽, рассчитанной по заданному вами курсу.

Возможности
💱 Конвертация shares → рубли по пользовательскому курсу

🔄 Мгновенный пересчёт всех ставок при изменении курса

💾 Курс сохраняется между сессиями (chrome.storage.sync)

⚡ Автоматическое обновление при появлении новых ставок на странице

🎯 Работает только на polymarket.com

Установка
Скачайте или склонируйте репозиторий:

bash
git clone https://github.com/your-username/polymarket-rub-converter.git
Откройте Chrome и перейдите в chrome://extensions/

Включите Режим разработчика (тумблер в правом верхнем углу)

Нажмите Загрузить распакованное расширение и выберите папку с проектом

Расширение установится и появится на панели инструментов

Использование
Кликните на иконку расширения на панели Chrome

Введите текущий курс рубля к доллару (например 95.50)

Нажмите Сохранить

Откройте polymarket.com — рядом с каждой ставкой появится зелёный бейдж с суммой в рублях

Пример
Ставка 5,641 @ 1.82 при курсе 95.50 ₽ отобразится как:

text
5,641 @ 1.82  ≈ 538.72K ₽
Формат отображения
Диапазон	Формат	Пример

1 000 – 999 999 ₽	X.XXK ₽	538.72K ₽
≥ 1 000 000 ₽	X.XXM ₽	1.23M ₽

Как это работает
Popup сохраняет курс в chrome.storage.sync — он синхронизируется между устройствами, если вы залогинены в Chrome.

Content script находит на странице <span> с текстом вида shares @ price (регулярка ^([\d\s.,]+)\s*@\s*([\d.,]+)$).

Парсит shares (корректно обрабатывает запятую как разделитель тысяч: 5,641 → 5641).

Умножает на курс и вставляет зелёный бейдж после элемента.

MutationObserver отслеживает изменения DOM, чтобы бейджи появлялись на новых ставках (при скролле, фильтрации, смене вкладок).

При изменении курса через chrome.storage.onChanged все бейджи пересчитываются моментально.

Права доступа
Расширение запрашивает минимально необходимые права:

storage — для сохранения курса рубля

host_permissions: https://polymarket.com/* — чтобы работать только на этом сайте

Расширение не собирает и не отправляет никакие данные на сторонние серверы.

Известные ограничения
Курс задаётся вручную (автоматическое получение с ЦБ РФ не реализовано)

Запятая в shares интерпретируется как разделитель тысяч (5,641 = 5641), а не как десятичный разделитель

Работает только в Chrome и браузерах на движке Chromium (Edge, Brave, Arc)

Разработка
После внесения изменений в код:

Перейдите в chrome://extensions/

Нажмите кнопку Обновить на карточке расширения

Перезагрузите страницу Polymarket

Логи content-скрипта можно смотреть в DevTools → Console на странице polymarket.com.
